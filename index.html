4. Formal Definition

The language is L = { w ∈ Σ* : |w| = 10, w[1] ∈ {1..9} } — exactly ten digits, first digit non-zero.

M = (Q, Σ, δ, q₀, F)

  • Q = { q0, q1, …, q10, qd }
  • Σ = { 0,1,…,9 } ∪ { any other character }
  • q₀ = q0    F = { q10 }
  • δ(q0, d) = q1 for d ∈ {1..9}; δ(q0, 0) = qd
  • δ(qi, d) = q(i+1) for 1 ≤ i ≤ 9, d ∈ {0..9}
  • δ(q10, any) = qd; δ(qd, any) = qd; non-digit → qd

Transition table

Note: real PNRs are 10 digits; the first three digits identify the PRS. This project models the structural rule (length + numeric + non-zero first digit). It cannot check whether a ticket actually exists — that needs IRCTC's database.
